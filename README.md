# Mia-teorology 🐱🌦

A weather forecast comparison and accuracy tracker.

The site compares forecasts from multiple sources and tracks how accurate they are over time, with Richmond, VA as the default location.

## Features

- Daily forecast accuracy leaderboard
- Forecast comparison between:
  - NWS (National Weather Service)
  - Open-Meteo
  - MET Norway
- Blended forecast combining all sources
- Hourly and daily blended forecasts
- 1-year historical accuracy backfill for Open-Meteo
- Toggle between live accuracy and historical analysis

## How it works

Every day a GitHub Action:

1. Collects forecasts from multiple weather APIs
2. Saves a snapshot of the predictions
3. Pulls observed weather data
4. Scores each forecast based on error
5. Updates the leaderboard

The site then displays this data using static JSON files.

## Connected home forecast tools

The page includes a scrollable next-24-hours forecast (temperature trend, rain chance, and wind), plus an activity planner for a walk, errands, or patio time in the next 48 hours. The planner ranks complete, consecutive daytime hours by rain, wind, and temperature; it excludes moderate/strong thunder or snow signals and never fills missing hourly values with zero. Its suggestions are forecasts, not live conditions or safety guarantees.

Today's icon uses the same `assets/weather-shared.js` classification and SVG artwork as Hubert's House. Keep that file byte-for-byte identical to `HubertsHouse/weather-shared.js` when changing it. Quiet summary text does not imply sunshine: the underlying source summaries determine cloud cover. Today is selected using Richmond's date.

Forecast files load independently of accuracy history and are checked every five minutes while visible, when returning to the tab, or with Refresh. Data is still generated by the existing scheduled workflow; checking does not generate new observations. Files older than 72 hours are unavailable; the toolbar marks daily forecasts older than 36 hours. Forecast refresh preserves the selected accuracy view.

Run `npm test` for forecast/planner regression tests and `npm run check` for frontend syntax checks. GitHub Pages publishes `main` directly. These frontend changes do not rewrite any weather history or change the data-generation workflow.
