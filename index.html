A few things worth knowing

The blend
A simple average of available sources. Missing readings stay missing; the source count can vary by hour and metric. ICON does not supply rain probabilities in this feed. ICON and the Open-Meteo forecast share an API service; model forecasts are not statistically independent.
The score
Recent accuracy compares forecast high/low, wind, and rain events with Richmond observations. Historical mode compares only Open-Meteo temperatures with reanalysis. ICON starts building accuracy history from new forecast snapshots; it has no invented or backfilled scores.
The timing
Forecasts are collected by the scheduled weather job. Refresh checks for newly published data; it does not generate a new forecast.
The playful part
Rainbow Watch is a rain-and-clearing index out of 100, not a scientific probability. Outside windows are planning suggestions based on available forecasts.
